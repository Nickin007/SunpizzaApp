# 饿了么 - 成本分析模块

## 📋 模块概述

成本分析模块用于管理和分析外卖订单的成本结构，帮助优化成本配置和提高利润率。

## 🎯 主要功能

### 1. 成本看板 📊
- 展示整体成本概览数据
- 统计总订单数、总成本、平均成本率
- 显示成本趋势分析
- 可视化成本分析图表

### 2. 日历面板 📅
- 以日历形式展示每日成本数据状态
- 查看特定日期的成本解析情况
- 跟踪成本数据上传和计算进度

### 3. 应用门店 🏪
- 配置哪些门店应用成本解析功能
- 启用/禁用特定门店的成本分析
- 管理门店级别的成本配置
- 查看最后同步时间

### 4. 源成本库 💰
- 管理原材料成本基础数据
- 维护包装、人工等成本项
- 支持批量导入成本数据
- 按类别筛选和搜索成本项
- 记录供应商信息

### 5. 订单解析数据库 📝
- 查看已解析的订单成本数据
- 按日期、门店、状态筛选订单
- 显示订单金额、成本金额、成本率
- 查看解析状态和详细信息
- 支持重新解析订单

## 🚀 技术实现

### 前端技术栈
- React + TypeScript
- Ant Design UI组件库
- React Router for路由管理
- dayjs for日期处理

### 组件结构
```
CostMapping.tsx (主组件)
├── CostDashboardTab.tsx (成本看板)
├── CostCalendarTab.tsx (日历面板)
├── AppliedStoresTab.tsx (应用门店)
├── SourceCostLibraryTab.tsx (源成本库)
└── OrderParseDataTab.tsx (订单解析数据库)
```


## 🎨 UI设计特点

1. **统一风格**：与数据管理页面保持一致的设计语言
2. **标签页导航**：清晰的功能分类，便于快速切换
3. **图标增强**：每个标签页都有相应的图标，提升可识别性
4. **响应式布局**：适配不同屏幕尺寸
5. **数据可视化**：使用卡片、表格、日历等多种展示方式
