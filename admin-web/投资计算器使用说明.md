# 门店投资计算器 - 使用说明

## 功能概述

门店投资计算器是一个专业的财务分析工具，用于评估新开门店的投资可行性。通过输入投资成本、运营费用和销售预测，系统自动生成完整的财务分析报告。

## 访问方式

1. 登录管理后台（账号：admin，密码：admin123）
2. 在左侧导航栏点击"投资计算器"图标
3. 进入投资计算器页面

## 页面布局

### 左侧：参数输入区（固定宽度）
- 四组折叠面板，包含所有输入参数
- 支持实时计算，修改任何参数后自动更新结果
- 提供"计算"和"重置"按钮

### 右侧：结果展示区（滚动查看）
- 风险评估
- 关键指标卡片
- 成本分析
- 可视化图表
- 详细财务报表
- 投资建议

## 参数说明

### A组：一次性初始投资

| 参数名称 | 说明 | 示例值 |
|---------|------|--------|
| 年租金 | 一年的租金总额 | 100,000元 |
| 装修费用 | 门店装修的总费用 | 80,000元 |
| 设备采购成本 | 厨房设备、收银系统等 | 50,000元 |
| 加盟费 | 品牌加盟费用 | 30,000元 |
| 保证金 | 加盟保证金 | 20,000元 |
| 首期租金押金 | 通常为1-3个月租金 | 20,000元 |
| 证照办理费 | 营业执照、食品经营许可证等 | 5,000元 |
| 首批原材料采购费 | 开业时的原材料储备 | 10,000元 |
| 开业营销推广费 | 开业活动、广告投放等 | 10,000元 |

**初始投资总额 = 所有A组参数之和**（默认示例：325,000元）

### B组：每月运营成本

#### 人员薪资
- **员工薪资**：所有员工月薪总和（示例：15,000元/月）
- **老板薪资**：店长或老板的薪资（示例：8,000元/月）

#### 水电杂费
- **水电杂费**：水费、电费、燃气费等（示例：3,000元/月）
- **物业管理费**：物业费、垃圾处理费等（示例：2,000元/月）
- **系统维护费**：收银系统、外卖平台等（示例：500元/月）

#### 营销费用（按营业额百分比）
- **推广CPC费用**：平台推广点击付费（示例：5%）
- **销售CPS费用**：销售佣金（示例：3%）

#### 品牌费用（按营业额百分比）
- **品牌管理费**：品牌使用费（示例：2%）

### C组：销售预测与收入结构

#### 外卖部分
| 参数 | 说明 | 示例值 |
|------|------|--------|
| 节假日日均订单量 | 节假日每天的外卖订单数 | 50单 |
| 节假日单均收入 | 每单平均收入 | 80元 |
| 工作日日均订单量 | 工作日每天的外卖订单数 | 30单 |
| 工作日单均收入 | 每单平均收入 | 75元 |

#### 到店自取部分
| 参数 | 说明 | 示例值 |
|------|------|--------|
| 节假日日均订单量 | 节假日每天的到店订单数 | 20单 |
| 节假日单均收入 | 每单平均收入 | 90元 |
| 工作日日均订单量 | 工作日每天的到店订单数 | 10单 |
| 工作日单均收入 | 每单平均收入 | 85元 |

#### 时间参数
- **每月节假日天数**：一般为8天（周末+法定节假日）
- **每月工作日天数**：一般为22天

**月度营业额计算公式：**
```
外卖收入 = (节假日订单量 × 节假日单价 × 节假日天数) + 
          (工作日订单量 × 工作日单价 × 工作日天数)
到店收入 = (节假日订单量 × 节假日单价 × 节假日天数) + 
          (工作日订单量 × 工作日单价 × 工作日天数)
月度营业额 = 外卖收入 + 到店收入
```

### D组：成本率参数

- **产品成本率**：原材料成本占营业额的百分比（示例：35%）
  - 行业标准：30%-40%
  - 低于30%：成本控制优秀
  - 高于40%：需要优化供应链或提高售价

## 输出结果说明

### 1. 风险评估

系统根据投资回报周期自动判断风险等级：

| 回本周期 | 风险等级 | 颜色标识 | 建议 |
|---------|---------|---------|------|
| < 24个月 | 低风险 | 绿色 | 投资前景良好 |
| 24-36个月 | 中风险 | 橙色 | 需关注市场变化 |
| > 36个月 | 高风险 | 红色 | 建议谨慎投资 |

### 2. 关键指标卡片

#### 投资回报周期（ROI）
- **定义**：初始投资总额 ÷ 月度净利润
- **单位**：月
- **示例**：325,000 ÷ 38,000 ≈ 8.5个月

#### 盈亏平衡点
- **定义**：实现收支平衡所需的最低月度营业额
- **计算公式**：固定成本 ÷ (1 - 变动成本率)
- **用途**：如果实际营业额低于此值，则会亏损

#### 月度净利润
- **计算公式**：月度营业额 - 月度总成本
- **正值**：盈利（绿色显示）
- **负值**：亏损（红色显示）

#### 年度预计利润
- **计算公式**：月度净利润 × 12
- **用途**：评估年度盈利能力

### 3. 成本分析

显示成本结构明细：
- 初始投资总额
- 月固定成本（人员、租金、水电等）
- 月变动成本（原材料、营销费用等）
- 月度总成本

### 4. 可视化图表

#### 成本结构饼图
展示各项成本在总成本中的占比：
- 初始投资
- 人员成本（年化）
- 租金成本（年化）
- 产品成本（年化）
- 运营费用（年化）

#### 12个月利润趋势折线图
- **X轴**：月份（1-12月）
- **Y轴**：累计利润
- **盈亏平衡线**：红色虚线标注
- **用途**：预测何时可以收回初始投资

#### 收入来源结构图
环形饼图展示：
- 外卖收入占比
- 到店自取收入占比

#### 敏感性分析柱状图
分析关键参数变化对利润的影响：
- **订单量变化**：-20%, -10%, 0%, +10%, +20%
- **成本率变化**：-10%, -5%, 0%, +5%, +10%
- **用途**：识别业务风险点和增长机会

#### 多场景对比雷达图
对比三种场景：
- **乐观场景**：订单量+30%，成本率-5%
- **正常场景**：按当前输入数据
- **悲观场景**：订单量-30%，成本率+5%

对比维度：
- 月度营业额
- 月度利润
- 年度利润
- 利润率
- 回本月数

### 6. 投资建议

系统根据计算结果自动生成投资建议，包括：

## 使用场景

### 场景1：新店选址评估
**步骤**：
1. 根据商圈调研填入预计的订单量和客单价
2. 根据房东报价填入租金
3. 查看投资回报周期和盈亏平衡点
4. 对比多个选址的数据，选择最优方案

### 场景2：价格策略制定
**步骤**：
1. 保持其他参数不变
2. 调整"单均收入"参数（提价或降价）
3. 观察利润率变化
4. 查看敏感性分析，评估订单量可能的下降
5. 找到最优价格点

### 场景3：成本优化分析
**步骤**：
1. 尝试降低不同的成本参数
2. 观察对月度利润和回本周期的影响
3. 对比成本结构饼图，识别优化重点
4. 制定成本控制策略

### 场景4：目标订单量计算
**步骤**：
1. 设定期望的月度利润目标
2. 反向调整订单量参数
3. 查看需要达到的订单量
4. 评估市场容量是否支持

## 注意事项

1. **数据准确性**
   - 尽量使用真实的市场调研数据
   - 成本预估要充分考虑隐性成本
   - 订单量预测要保守一些

2. **动态调整**
   - 实时计算功能可以快速试错
   - 建议多次尝试不同参数组合
   - 关注多场景对比结果

3. **风险意识**
   - 如果悲观场景下会亏损，需要慎重
   - 回本周期超过36个月风险较高
   - 建议准备3-6个月的运营资金储备

4. **局限性**
   - 计算结果仅供参考，不构成投资建议
   - 实际经营受多种因素影响
   - 建议结合实际情况综合判断

## 常见问题

### Q1：为什么我的投资回报周期显示"∞"？
**A**：说明月度净利润为负数或零，无法收回投资。建议：
- 提高订单量或客单价
- 降低固定成本（如租金、人员）
- 降低产品成本率

### Q2：利润率多少算合理？
**A**：餐饮行业一般标准：
- 10%-15%：基本合格
- 15%-25%：良好
- 25%以上：优秀

### Q3：如何使用敏感性分析？
**A**：
1. 查看订单量变化的影响：如果-10%就亏损，说明风险很高
2. 查看成本率变化的影响：如果+5%就大幅亏损，说明成本控制很重要
3. 识别哪个因素对利润影响更大，重点优化

### Q4：三种场景的假设是否合理？
**A**：
- 乐观场景：适用于位置优越、营销得力的情况
- 正常场景：基于你的输入数据
- 悲观场景：适用于竞争激烈、市场萎缩的情况
- 建议：根据实际市场情况调整预期

### Q5：如何导出报告？
**A**：当前版本支持浏览器打印功能：
1. 点击浏览器的打印按钮（Ctrl+P）
2. 选择"另存为PDF"
3. 保存完整报告

未来版本将支持一键导出Excel和PDF功能。
