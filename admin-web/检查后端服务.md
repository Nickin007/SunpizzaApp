# 检查后端服务器状态

## 🔍 方法一：SSH 登录服务器检查

### 1. 连接到服务器
```powershell
ssh ubuntu@118.89.73.199
```

### 2. 检查服务状态
```bash
sudo systemctl status sunpizza-backend
```

**正常输出应该显示：**
```
● sunpizza-backend.service - SunPizza Backend Service
     Loaded: loaded (/etc/systemd/system/sunpizza-backend.service; enabled; vendor preset: enabled)
     Active: active (running) since ...
```

如果状态是 `inactive (dead)` 或 `failed`，说明服务未运行。

### 3. 查看日志
```bash
# 查看最新 50 行日志
tail -n 50 ~/SunpizzaApp/backend/logs/gunicorn_error.log

# 实时查看日志
tail -f ~/SunpizzaApp/backend/logs/gunicorn_error.log
```

### 4. 重启服务（如果需要）
```bash
sudo systemctl restart sunpizza-backend
```

### 5. 查看进程
```bash
ps aux | grep gunicorn
```

## ⚠️ 常见问题排查

### 问题 1：连接超时
**原因：** 后端服务未运行或防火墙阻止
**解决：** 
1. SSH登录服务器
2. 运行 `sudo systemctl restart sunpizza-backend`
3. 检查防火墙：`sudo ufw status`

### 问题 2：CORS 错误
**原因：** 后端未配置跨域访问
**解决：** 检查 `backend/app/__init__.py` 中的 CORS 配置

### 问题 3：401 未授权
**原因：** 用户名或密码错误
**解决：** 确认使用 `admin / admin123`

### 问题 4：500 服务器错误
**原因：** 后端代码错误或数据库连接失败
**解决：** 查看日志 `tail -n 100 ~/SunpizzaApp/backend/logs/gunicorn_error.log`

## 📊 完整的健康检查脚本

创建一个检查脚本 `check_backend.sh`：

```bash
#!/bin/bash

echo "🔍 检查后端服务状态..."
echo ""

# 1. 检查服务状态
echo "1️⃣ 服务状态:"
sudo systemctl status sunpizza-backend --no-pager

echo ""
echo "2️⃣ 进程状态:"
ps aux | grep gunicorn | grep -v grep

echo ""
echo "3️⃣ 端口监听:"
sudo netstat -tlnp | grep 5000

echo ""
echo "4️⃣ 最新日志:"
tail -n 20 ~/SunpizzaApp/backend/logs/gunicorn_error.log

echo ""
echo "5️⃣ API 测试:"
curl -s http://localhost:5000 || echo "❌ API 无响应"
```

使用方法：
```bash
# 赋予执行权限
chmod +x check_backend.sh

# 运行检查
./check_backend.sh
```
