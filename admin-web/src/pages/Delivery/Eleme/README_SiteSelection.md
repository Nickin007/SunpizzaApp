# 选址工具版本说明

## 📋 版本对比

### SiteSelection.tsx（旧版本）
- ✅ 单品牌搜索
- ✅ 实时从高德API获取数据
- ✅ 搜索并保存到数据库
- ❌ 不支持多品牌对比
- ❌ 不支持历史数据查询
- ❌ 不支持品牌颜色区分

### SiteSelectionV2.tsx（新版本）✨
- ✅ 多品牌同时显示
- ✅ 数据库管理（查询已保存的品牌）
- ✅ 品牌POI数据更新（从高德API）
- ✅ 品牌颜色自动分配
- ✅ 品牌可见性控制（显示/隐藏）
- ✅ 实时统计信息
- ✅ 竞品对比分析

---

## 🎯 新版本功能详解

### 1. 城市选择
- 选择城市后自动加载该城市的品牌列表

### 2. 数据库更新
- **输入品牌关键词**（支持自动补全）
- **点击"更新该品牌POI数据库"**
- 从高德地图API获取最新数据并保存到数据库

### 3. 品牌选择
- **查看所有已保存的品牌**
  - 显示门店数量
  - 显示品牌类别（披萨类/炸鸡类/奶茶类等）
  - 品牌颜色标识
- **选择要对比的品牌**
  - 支持多选
  - 支持全选/清空
- **点击"加载选中品牌"**
  - 从数据库查询门店数据
  - 在地图上显示多个品牌（不同颜色）

### 4. 品牌显示控制
- **加载后可以控制每个品牌的显示/隐藏**
  - 点击眼睛图标切换可见性
  - 不同品牌用不同颜色区分
  - 显示每个品牌的门店数量

### 5. 统计信息
- 显示当前加载的品牌数
- 显示总门店数

## 🚀 使用流程

### 第一次使用
```
1. 选择城市（如：杭州）
2. 在"数据库更新"输入品牌（如：必胜客）
3. 点击"更新该品牌POI数据库"
4. 等待更新完成
5. 重复2-4步骤添加更多品牌（如：肯德基、麦当劳）
```

### 日常使用
```
1. 选择城市
2. 在"品牌选择"中勾选要对比的品牌
3. 点击"加载选中品牌"
4. 查看地图上的多品牌分布
5. 使用"品牌显示控制"切换显示/隐藏
```

### 更新数据
```
当需要更新某个品牌的最新数据时：
1. 在"数据库更新"输入品牌名
2. 点击"更新该品牌POI数据库"
3. 系统会自动刷新品牌列表
4. 如果该品牌已被选中，会自动重新加载
```

## 📊 数据说明

### 数据来源
- 高德地图POI API
- 实时抓取最新门店信息

### 数据库存储
- 表名：`poi_stores`
- 字段：品牌名、门店名、地址、经纬度、电话、类别等
- 更新策略：如果门店已存在则更新，否则新增

### 数据准确性
- 数据来自高德地图官方API
- 建议定期更新（如每月更新一次）
- 更新时会覆盖旧数据

## 🔧 技术实现

### 后端API
```
GET  /api/poi/brands       - 获取品牌列表
GET  /api/poi/stores       - 获取门店数据（支持多品牌）
POST /api/poi/search       - 搜索并保存POI数据
```

### 前端技术
- React Hooks（useState, useEffect, useRef）
- 高德地图 API 1.4.15
- Ant Design UI组件

### 性能优化
- 标记按品牌分组管理
- 支持单个品牌显示/隐藏
- 地图视野自动调整

## 📝 常见问题

### Q: 为什么看不到品牌列表？
A: 需要先使用"数据库更新"功能添加品牌数据。

### Q: 如何添加新品牌？
A: 在"数据库更新"输入品牌名，点击更新即可。

### Q: 支持哪些城市？
A: 支持浙江省所有城市及主要一二线城市。

### Q: 数据多久更新一次？
A: 手动更新，建议每月更新一次。

### Q: 可以对比多少个品牌？
A: 理论上无限制，但建议同时对比不超过10个品牌以保证地图可读性。
