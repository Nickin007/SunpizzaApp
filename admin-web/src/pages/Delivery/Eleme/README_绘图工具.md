# 地图绘图工具使用说明

## 功能概述

多品牌选址对比工具现在支持强大的地图绘图功能，包括：

### 📐 测距工具
- **功能**：测量地图上两点之间的直线距离
- **操作**：
  1. 点击"测距"按钮
  2. 在地图上点击起点
  3. 再点击终点
  4. 系统会自动显示距离（单位：米/公里）
  5. 可以继续点击添加多个测量点
  6. 双击结束测距

### 🎨 绘图工具

#### 1. 标记点 (Marker)
- **图标**：📍
- **用途**：在地图上标注重要位置
- **操作**：点击"标记点"按钮，然后在地图上点击放置标记

#### 2. 折线 (Polyline)
- **图标**：—
- **用途**：绘制路线、规划路径
- **操作**：
  1. 点击"折线"按钮
  2. 在地图上依次点击多个点
  3. 双击结束绘制
- **样式**：蓝色线条，宽度6px

#### 3. 多边形 (Polygon)
- **图标**：◻
- **用途**：圈定区域范围（如商圈、配送范围）
- **操作**：
  1. 点击"多边形"按钮
  2. 在地图上依次点击多个点
  3. 双击结束绘制（自动闭合）
- **样式**：蓝色半透明填充

#### 4. 圆形 (Circle)
- **图标**：◯
- **用途**：标注辐射范围（如3公里配送半径）
- **操作**：
  1. 点击"圆形"按钮
  2. 在地图上点击确定圆心
  3. 拖动鼠标确定半径
  4. 释放鼠标完成绘制
- **样式**：橙色半透明填充

#### 5. 矩形 (Rectangle)
- **图标**：▭
- **用途**：框选矩形区域
- **操作**：
  1. 点击"矩形"按钮
  2. 在地图上点击并拖动
  3. 释放鼠标完成绘制
- **样式**：绿色半透明填充

## 🛠️ 操作按钮

### 关闭工具
- 关闭当前激活的绘图模式
- 不会删除已绘制的图形

### 清除 (N)
- **功能**：删除所有已绘制的图形
- **显示**：括号中显示当前绘制图形的数量
- **确认**：点击后会弹出确认对话框，防止误删

## 💡 使用场景示例

### 场景1：测量竞品距离
1. 加载"必胜客"和"达美乐"品牌
2. 使用"测距"工具测量两家门店之间的距离
3. 评估竞争强度

### 场景2：圈定商圈范围
1. 加载住宅区、学校等POI
2. 使用"多边形"工具圈定目标商圈
3. 分析商圈内的POI分布密度

### 场景3：规划配送半径
1. 选择一个门店位置
2. 使用"圆形"工具绘制3公里配送半径
3. 查看覆盖范围内的住宅区数量

### 场景4：划定选址候选区域
1. 使用"矩形"或"多边形"框选多个候选区域
2. 对比不同区域的竞品密度
3. 辅助选址决策

## ⚠️ 注意事项

1. **切换工具**：激活新工具时，之前的工具会自动关闭
2. **保留图形**：切换工具不会删除已绘制的图形
3. **清除确认**：清除操作会删除所有图形，请谨慎操作
4. **性能考虑**：绘制大量复杂图形可能影响地图性能，建议及时清理不需要的图形

## 🎨 界面说明

- **蓝色按钮**：表示该工具正在激活
- **灰色按钮**：表示该工具未激活
- **标签显示**：右上角显示当前工具状态（"测距中"或"绘制中"）
- **计数显示**：清除按钮显示当前图形数量

## 🔧 技术实现

本功能基于高德地图官方插件：
- `AMap.MouseTool`：鼠标绘图工具
- `AMap.RangingTool`：测距工具

所有绘制的图形都存储在 `drawOverlaysRef` 中，支持批量管理和清除。

## 📱 移动端支持

绘图工具在移动端（平板、手机）上同样可用，触摸操作方式：
- 点击 = 鼠标点击
- 长按拖动 = 鼠标拖动
- 双击 = 完成绘制
