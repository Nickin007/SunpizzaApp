# 🌍 环境配置说明

## 📋 快速切换环境

所有环境配置都在 `lib/core/config/environment.dart` 文件中。

## 🔧 开发环境配置（手机真机调试）

### 步骤 1：获取你的电脑 IP 地址

在 PowerShell 中执行：

```powershell
ipconfig | findstr "IPv4"
```

会显示类似：
```
   IPv4 地址 . . . . . . . . . . . . : 192.168.1.100
```

### 步骤 2：修改开发环境 API 地址

打开 `lib/core/config/environment.dart`，修改第 18 行：

```dart
/// 开发环境配置
static const String developmentApiUrl = 'http://192.168.1.100:5000'; // 👈 改成你的电脑 IP
```

### 步骤 3：确保当前环境为开发环境

在 `lib/core/config/environment.dart` 第 14 行，确保设置为：

```dart
static const Environment currentEnvironment = Environment.development;
```

- 电脑连接的 WiFi：`___________`
- 手机连接的 WiFi：`___________`（必须相同）

### 步骤 5：启动后端服务器

```powershell

.\venv\Scripts\Activate.ps1
python app.py
```

后端应该显示：
```

* Running on http://192.168.1.100:5000
```

### 步骤 6：运行 Flutter 应用


```
========================================
```

## 🚀 生产环境配置（部署到服务器）

### 步骤 1：修改生产环境 API 地址

打开 `lib/core/config/environment.dart`，修改第 21 行：

```dart
/// 生产环境配置
static const String productionApiUrl = 'https://api.sunpizza.com'; // 👈 改成你的服务器域名
```

### 步骤 2：切换到生产环境

在 `lib/core/config/environment.dart` 第 14 行，修改为：

```dart
static const Environment currentEnvironment = Environment.production;
```

### 步骤 3：重新编译应用

```powershell
# 清理缓存
flutter clean

# 重新构建
flutter build apk --release

# 生成的 APK 在：
# build/app/outputs/flutter-apk/app-release.apk
```

## ⚠️ 注意事项

1. **开发环境**：
   - ✅ 电脑和手机必须在同一个 WiFi
   - ✅ 后端必须运行在电脑上（`python app.py`）
   - ✅ 防火墙要允许 5000 端口
   - ❌ 不能使用 `localhost` 或 `127.0.0.1`

2. **生产环境**：
   - ✅ 服务器必须已部署后端
   - ✅ 建议使用 HTTPS（安全）
   - ✅ 域名要配置正确的 DNS

3. **切换环境后**：
   - ✅ 必须重新运行 `flutter run` 或重新编译
   - ✅ 检查控制台打印的环境信息是否正确

## 📝 常见问题

### Q1: 手机登录时显示"网络错误"
**A:** 检查：
1. 电脑和手机是否在同一 WiFi
2. 后端是否正在运行（`python app.py`）
3. `environment.dart` 中的 IP 地址是否正确
4. 防火墙是否阻止了 5000 端口

### Q2: 如何知道当前是哪个环境？
**A:** 应用启动时会在控制台打印环境信息。

### Q3: 切换环境后没有生效
**A:** 必须重新运行 `flutter run` 或重新编译应用。
