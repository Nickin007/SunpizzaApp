## 模块概述

圣比萨培训模块是一个完整的企业培训解决方案，支持视频学习、文档阅读、在线考试和自动/手动评分。

### 核心特性
- **多媒体学习**: 支持视频、富文本文档
- **灵活考试**: 客观题自动判分，主观题人工评分
- **学习追踪**: 记录视频观看进度、文档阅读状态
- **审核机制**: 管理员审核主观题答案并给出反馈

---

## 功能特性

### 1. 培训分类
- **产品类培训**: 披萨制作、原料知识、产品标准等
- **服务类培训**: 客户服务礼仪、投诉处理、沟通技巧等
- **运营类培训**: 门店管理、库存管理、卫生规范等

### 2. 课程内容
每个课程可包含：
- 📹 **视频**: 支持在线播放，自动保存播放进度
- 📄 **文档**: 富文本格式，支持图片、列表、格式化文本
- 📝 **考试**: 单选、多选、判断、主观题

### 3. 考试系统
- **客观题**: 自动判分（单选、多选、判断）
- **主观题**: 管理员审核评分
- **状态管理**:
  - `pending_review`: 待审核（等待管理员评分主观题）
  - `passed`: 已通过（总分 ≥ 及格分）
  - `failed`: 未通过（总分 < 及格分）

## Web端管理

### 访问路径
登录后在侧边栏找到 **「培训模块」** → **「课程管理」** 或 **「考试审核」**

### 1. 课程管理
**路径**: `/training`

**功能**:
- ✅ 查看所有课程列表
- ✅ 创建新课程（标题、描述、分类、视频URL、富文本文档）
- ✅ 编辑课程信息
- ✅ 删除课程（需要没有学习记录）
- ✅ 发布/下架课程（控制是否在APP显示）

**操作步骤**:
1. 点击「新增课程」按钮
2. 填写课程基本信息：
   - **标题**: 课程名称
   - **描述**: 简短说明（显示在列表中）
   - **分类**: 选择产品/服务/运营类
   - **视频地址**: 填写视频URL（可选）
   - **文档内容**: 使用富文本编辑器编写（可选）
   - **是否包含考试**: 打开此选项后才能添加题目
   - **是否发布**: 是否在APP中显示
3. 点击「确定」保存

### 2. 题目管理
**路径**: `/training/questions/:courseId`

**功能**:
- ✅ 查看课程的所有题目
- ✅ 单个添加题目
- ✅ 批量导入题目（支持自定义格式）
- ✅ 编辑题目内容、选项、答案、分值
- ✅ 删除题目

**题目类型**:
- **单选题** (`single_choice`): 一个正确答案
- **多选题** (`multiple_choice`): 多个正确答案（逗号分隔）
- **判断题** (`true_false`): 正确/错误
- **主观题** (`subjective`): 需要管理员评分

**批量导入格式**:
```
Q:披萨面团发酵的标准时间是？
-30分钟
-1小时
-2小时
-3小时
A:1小时

Q:披萨酱料中需要哪些调料？（多选）
-罗勒
-牛至
-孜然
-大蒜末
A:罗勒,牛至,大蒜末

Q:请简述披萨制作过程中最重要的三个注意事项。
主观:
```

### 3. 考试审核
**路径**: `/training/exam-review`

**功能**:
- ✅ 查看待审核的考试列表
- ✅ 查看学员的详细答题情况
- ✅ 给主观题评分
- ✅ 设置及格分数（默认60分）
- ✅ 填写审核反馈

**审核步骤**:
1. 点击「审核」按钮查看考试详情
2. 系统自动显示：
   - 客观题得分（已自动判分）
   - 每道题的答题情况
   - 主观题的学员回答
3. 输入主观题得分
4. 输入及格分数（默认60）
5. 填写反馈意见（可选）
6. 点击「确定」完成审核

**计算方式**:
```
总分 = 客观题得分 + 主观题得分

如果 总分 >= 及格分数:
    状态 = 已通过
否则:
    状态 = 未通过
```

## APP端学习

### 1. 培训中心
**路径**: 首页 → **「培训中心」** 标签页

**功能**:
- 📚 浏览所有培训课程（按分类筛选）
- 🔍 查看课程详情（标题、描述、状态）
- 📊 查看学习进度（未开始、学习中、已完成、已通过）

**分类标签**:
- 全部
- 产品类
- 服务类
- 运营类

### 2. 课程详情
**路径**: 培训中心 → 点击课程卡片

**包含三个标签页**:

#### 📹 视频学习
- 在线播放视频
- 自动保存播放进度（每10秒）
- 断点续播（重新打开时从上次位置继续）

#### 📄 文档阅读
- 查看富文本文档（支持HTML格式）
- 点击「标记为已读」按钮记录学习进度

#### 📝 课程考试
- 显示考试状态（未参加、待审核、已通过、未通过）
- 点击「开始考试」进入答题页面
- 只能提交一次，提交后无法修改

### 3. 考试页面
**路径**: 课程详情 → 课程考试 → 开始考试

**功能**:
- 📝 按顺序作答所有题目
- 🔄 切换题目（顶部标签）
- ✅ 实时保存答案
- 📤 提交考试

**题目类型**:
- **单选题**: 单个选项卡片（点击选中）
- **多选题**: 多个选项卡片（可选多个）
- **判断题**: 正确/错误两个按钮
- **主观题**: 多行文本输入框

**提交流程**:
1. 完成所有题目作答
2. 点击「提交考试」按钮
3. 确认提交
4. 系统自动判分客观题
5. 等待管理员审核主观题

## 考试系统

### 评分机制

#### 客观题（自动判分）
- 系统在提交时立即计算得分
- 答案完全匹配才得分
- 多选题需要选择的选项完全一致

#### 主观题（人工评分）
- 管理员在Web端审核
- 根据答题质量给分
- 可以给出评分反馈

### 状态流转

```
学员提交考试
    ↓
pending_review (待审核)
    ↓
管理员评分主观题
    ↓
总分 >= 及格分? → 是 → passed (已通过)
                → 否 → failed (未通过)
```

### 学习记录

系统会记录以下信息:
- **视频进度**: 观看到第几秒
- **文档阅读**: 是否已阅读
- **考试状态**: 未参加、待审核、已通过、未通过
- **考试得分**: 客观题得分、主观题得分、总分

## 常见问题

### Q1: 视频无法播放？
**A**: 请检查：
1. 视频URL是否正确
2. 视频格式是否支持（推荐MP4）
3. 网络连接是否正常
4. 视频服务器是否允许跨域访问

### Q2: 考试提交后能修改吗？
**A**: 不能。每个课程的考试只能提交一次，提交后无法修改答案。

### Q3: 主观题什么时候能知道结果？
**A**: 提交考试后状态为「待审核」，需要等待管理员审核主观题并评分。审核完成后可以看到最终成绩和反馈。

### Q4: 如何删除已有学习记录的课程？
**A**: 不能删除。为了保证数据完整性，已有学习记录或考试提交的课程无法删除。可以选择「下架」课程，使其不在APP显示。

### Q5: 批量导入题目失败？
**A**: 请检查格式是否正确：
- Q: 开头表示题目
- \- 开头表示选项
- A: 开头表示答案
- 主观: 表示主观题
- 每个部分之间需要空行分隔

### Q6: 富文本编辑器支持哪些功能？
**A**: 支持：
- 标题（H1, H2, H3）
- 粗体、斜体、下划线、删除线
- 有序列表、无序列表
- 文字颜色、背景色
- 超链接
- 清除格式

## 技术实现

### 后端API
- **路径**: `/api/training/`
- **框架**: Flask + SQLAlchemy
- **数据库表**:
  - `training_categories`: 培训分类
  - `training_courses`: 课程信息
  - `exam_questions`: 考试题目
  - `learning_records`: 学习记录
  - `exam_submissions`: 考试提交

### 前端Web
- **框架**: React 18 + TypeScript + Vite
- **UI库**: Ant Design 5
- **富文本**: React Quill
- **路由**: React Router v7

### 前端APP
- **框架**: Flutter 3.x
- **视频播放**: video_player + chewie
- **HTML渲染**: flutter_html
- **网络请求**: dio
