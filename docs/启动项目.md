# 🚀 圣比萨APP - 项目启动指南

## 📋 前置准备

### 1. 安装必需软件

#### 后端环境
- ✅ Python 3.9 或更高版本
- ✅ MySQL 8.0 或更高版本

#### 前端环境
- ✅ Flutter SDK 3.0 或更高版本
- ✅ Chrome 浏览器（用于Web端测试）

### 2. 检查安装

打开命令行，运行以下命令检查：

```bash
# 检查Python版本
python --version
# 或
python3 --version

# 检查MySQL
mysql --version

# 检查Flutter
flutter --version

# 检查Flutter设备
flutter devices
```

## 🔧 第一步：启动后端服务

### 1. 打开命令行，进入后端目录

```bash
cd C:\Users\YQH20\Desktop\SunpizzaApp\backend
```

### 2. 创建Python虚拟环境

```bash
# Windows
python -m venv venv

# 激活虚拟环境
venv\Scripts\activate
```

激活成功后，命令行前面会显示 `(venv)`

### 3. 安装Python依赖包

```bash
pip install -r requirements.txt
```

等待安装完成（可能需要几分钟）

### 4. 配置数据库

#### 4.1 启动MySQL服务

确保MySQL服务已启动。如果没有启动：
- Windows: 在服务管理器中启动 MySQL80 服务
- 或在命令行运行：`net start MySQL80`

#### 4.2 创建数据库

打开新的命令行窗口，运行：

```bash
mysql -u root -p
```

输入MySQL密码后，执行：

```sql
CREATE DATABASE sunpizza_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;
```

#### 4.3 配置环境变量

在 `backend` 目录创建 `.env` 文件（如果还没有的话）：

```bash
# Windows PowerShell
notepad .env
```

在文件中写入（**请修改密码为你的MySQL密码**）：

```env
SECRET_KEY=sunpizza-dev-secret-key-2025
JWT_SECRET_KEY=sunpizza-jwt-secret-2025

MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=你的MySQL密码
MYSQL_DATABASE=sunpizza_db

FLASK_ENV=development
FLASK_DEBUG=1
```

保存并关闭文件。

### 5. 初始化数据库

```bash
python init_db.py
```

如果看到以下输出，说明成功：

```
正在删除现有表...
正在创建数据库表...
正在初始化字典表...
正在创建默认管理员账户...
管理员账户创建成功 - 用户名: admin, 密码: admin123
正在创建示例数据...
示例数据创建成功！
数据库初始化完成！
```

### 6. 启动Flask服务器

```bash
python app.py
```

如果看到：

```
 * Running on http://127.0.0.1:5000
```

说明后端启动成功！**保持这个窗口打开。**

### 7. 测试后端API

打开浏览器，访问：http://localhost:5000

应该看到：

```json
{
  "message": "欢迎使用圣比萨智能门店管理平台API",
  "version": "1.0.0",
  "status": "running"
}
```

## 🛠️ 常见问题

### Q1: Python虚拟环境激活失败

**问题**：运行 `venv\Scripts\activate` 时报错

**解决**：
```bash
# 尝试使用PowerShell激活
venv\Scripts\Activate.ps1

# 如果提示执行策略错误，以管理员身份运行PowerShell：
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### Q2: MySQL连接失败

**问题**：`Can't connect to MySQL server`

**解决**：
1. 确认MySQL服务已启动
2. 检查 `.env` 文件中的密码是否正确
3. 尝试在命令行登录MySQL测试：`mysql -u root -p`

### Q3: Flutter依赖下载慢

**问题**：`flutter pub get` 很慢或失败

**解决**：
```bash
# 使用国内镜像
$env:PUB_HOSTED_URL="https://pub.flutter-io.cn"
$env:FLUTTER_STORAGE_BASE_URL="https://storage.flutter-io.cn"

# 然后重新运行
flutter pub get
```

### Q4: 端口被占用

**问题**：`Address already in use: 5000`

**解决**：
```bash
# 查找占用5000端口的进程
netstat -ano | findstr :5000

# 结束进程（替换PID为实际进程号）
taskkill /PID <进程号> /F
```

### Q5: Chrome无法启动

**问题**：Flutter找不到Chrome

**解决**：
```bash
# 设置Chrome路径（替换为你的Chrome安装路径）
$env:CHROME_EXECUTABLE="C:\Program Files\Google\Chrome\Application\chrome.exe"

# 然后重新运行
flutter run -d chrome
```
