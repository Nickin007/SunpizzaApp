## 🔧 故障排查

### 问题 1：无法连接到服务器

**检查：**
1. 服务器是否正在运行
2. 腾讯云安全组是否开放了 22 端口（SSH）
3. 防火墙是否允许连接

### 问题 2：无法访问 API

**检查：**
1. 后端服务是否运行：`sudo systemctl status sunpizza-backend`
2. Nginx 是否运行：`sudo systemctl status nginx`
3. 腾讯云安全组是否开放了 80 端口
4. 防火墙规则：`sudo ufw status`

### 问题 3：API 返回 502 Bad Gateway

**可能原因：**
- 后端服务未启动或崩溃
- Gunicorn 配置错误

**解决：**
```bash
# 查看后端日志
tail -f /home/ubuntu/SunpizzaApp/backend/logs/gunicorn_error.log

# 重启服务
sudo systemctl restart sunpizza-backend
```

### 问题 4：数据库连接失败

**检查：**
```bash
# 测试数据库连接
mysql -u sunpizza_user -pSunpizza2025@DB -e "SELECT 1"

# 查看 MySQL 日志
sudo tail -f /var/log/mysql/error.log
```

### 3. 配置自动备份

```bash
# 创建数据库备份脚本
cat > /home/ubuntu/backup_db.sh << 'EOF'
#!/bin/bash
BACKUP_DIR="/home/ubuntu/backups"
DATE=$(date +%Y%m%d_%H%M%S)
mkdir -p ${BACKUP_DIR}
mysqldump -u sunpizza_user -pSunpizza2025@DB sunpizza_db > ${BACKUP_DIR}/sunpizza_db_${DATE}.sql
# 只保留最近 7 天的备份
find ${BACKUP_DIR} -name "*.sql" -mtime +7 -delete
EOF

chmod +x /home/ubuntu/backup_db.sh

# 添加到 crontab（每天凌晨 2 点备份）
(crontab -l 2>/dev/null; echo "0 2 * * * /home/ubuntu/backup_db.sh") | crontab -
```
