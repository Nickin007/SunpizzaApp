# 饿了么商家成长数据表设计

## 📊 数据表：`eleme_growth_data`

### 字段统计
- **基础信息**：8个字段
- **店铺评级**：2个字段
- **指标数据**：51个字段（12组×4字段 + 1组×3字段）
- **元数据**：2个字段
- **总计**：63个字段

## 📝 数据导入规则

### 1. 去重逻辑
**允许重复数据**（同一门店同一日期可能有多次数据更新记录）

### 2. 数据验证
- **必填字段**：`日期`、`门店名称`
- **日期格式**：支持 `YYYY-MM-DD`、`YYYY/MM/DD`
- **数值字段**：自动转换为 `DECIMAL`，无效值记为 `NULL`

## 🎯 查询示例

### 1. 查询某城市的店铺评分排名
```sql
SELECT 
    store_name, 
    store_score, 
    l_level,
    data_date
FROM eleme_growth_data
WHERE city = '杭州'
  AND data_date = '2025-10-19'
ORDER BY store_score DESC
LIMIT 10;
```

### 2. 查询某门店的指标完成情况
```sql
SELECT 
    data_date,
    peak_hours_7d_current,
    peak_hours_7d_target,
    peak_hours_7d_score,
    merchant_rating_current,
    merchant_rating_target,
    merchant_rating_score
FROM eleme_growth_data
WHERE store_id = 'STORE_12345'
ORDER BY data_date DESC
LIMIT 7;
```

### 3. 统计各城市的平均店铺分
```sql
SELECT 
    city,
    AVG(store_score) as avg_score,
    COUNT(*) as store_count,
    MAX(store_score) as max_score,
    MIN(store_score) as min_score
FROM eleme_growth_data
WHERE data_date = '2025-10-19'
GROUP BY city
ORDER BY avg_score DESC;
```

## 📌 注意事项

1. **字段数量多**：63个字段，前端展示需要分组或分页
2. **指标模式统一**：大部分指标包含4个字段（当前值、目标值、得分、权重）
3. **DECIMAL精度**：所有数值字段使用 `DECIMAL(10, 2)` 保留2位小数
4. **允许重复**：同一门店同一日期可能有多次数据更新
5. **索引优化**：重点索引 `data_date`, `store_id`, `city` 用于常见查询
