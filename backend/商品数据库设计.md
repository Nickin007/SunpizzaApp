# 饿了么商品数据库设计文档

## 📋 概述

本文档详细说明了饿了么商品数据表 `eleme_product_data` 的设计。该表用于存储从饿了么平台导出的商品销售与运营数据。

---

## 🗂️ 数据表结构

### 表名：`eleme_product_data`

### 字段清单（共 24 个核心字段）

#### 1️⃣ **基础信息** (5 个字段)

| 字段名 | 数据类型 | 是否必填 | 说明 | Excel列名 |
|--------|---------|---------|------|----------|
| `id` | INT | 是 | 自增主键 | - |
| `data_date` | DATE | 是 | 数据日期 | 日期 |
| `city` | VARCHAR(50) | 否 | 城市名称 | 城市名称 |
| `store_name` | VARCHAR(200) | 是 | 门店名称 | 门店名称 |
| `store_id` | VARCHAR(50) | 否 | 门店编号 | 门店编号 |
| `product_name` | VARCHAR(200) | 是 | 商品名称 | 商品名称 |

**索引**：
- `data_date` - 索引（按日期查询）
- `city` - 索引（按城市筛选）
- `store_name` - 索引（按门店查询）
- `store_id` - 索引（按门店ID查询）
- `product_name` - 索引（按商品名查询）

---

#### 2️⃣ **商品属性** (5 个字段)

| 字段名 | 数据类型 | 默认值 | 说明 | Excel列名 | 可能值 |
|--------|---------|-------|------|----------|--------|
| `is_new_product` | VARCHAR(10) | NULL | 是否新品 | 是否新品 | 是/否 |
| `is_signature` | VARCHAR(10) | NULL | 是否招牌商品 | 是否招牌 | 是/否 |
| `is_combo` | VARCHAR(10) | NULL | 是否套餐 | 是否套餐 | 是/否 |
| `is_ingredient` | VARCHAR(10) | NULL | 是否配料 | 是否配料 | 是/否 |
| `is_sold_out` | VARCHAR(10) | NULL | 是否售罄 | 是否售罄 | 是/否 |

**说明**：这些字段用于标识商品的业务属性，帮助分析不同类型商品的表现。

---

#### 3️⃣ **销售数据** (5 个字段)

| 字段名 | 数据类型 | 默认值 | 说明 | Excel列名 |
|--------|---------|-------|------|----------|
| `sales_amount` | DECIMAL(12, 2) | 0 | 销售额（元） | 销售额 |
| `sales_volume` | INT | 0 | 销量 | 销量 |
| `order_user_count` | INT | 0 | 下单人数 | 下单人数 |
| `order_count` | INT | 0 | 带来订单数 | 带来订单数 |
| `order_transaction_amount` | DECIMAL(12, 2) | 0 | 订单交易额（元） | 订单交易额 |

**核心指标**：
- **销售额**：该商品的总销售金额
- **销量**：该商品的总销售数量
- **下单人数**：购买该商品的用户数
- **带来订单数**：因该商品产生的总订单数
- **订单交易额**：包含该商品的订单总金额

---

#### 4️⃣ **复购数据** (2 个字段)

| 字段名 | 数据类型 | 默认值 | 说明 | Excel列名 |
|--------|---------|-------|------|----------|
| `repurchase_30d_users` | INT | 0 | 近30日复购人数 | 近30日复购人数 |
| `repurchase_30d_rate` | DECIMAL(5, 2) | NULL | 近30日复购率（%） | 近30日复购率 |

**说明**：衡量商品的用户粘性和回购价值。

---

#### 5️⃣ **新客数据** (2 个字段)

| 字段名 | 数据类型 | 默认值 | 说明 | Excel列名 |
|--------|---------|-------|------|----------|
| `new_customer_count` | INT | 0 | 新客人数 | 新客人数 |
| `new_customer_ratio` | DECIMAL(5, 2) | NULL | 新客占比（%） | 新客占比 |

**说明**：分析商品对新用户的吸引力。

---

#### 6️⃣ **用户行为数据** (5 个字段)

| 字段名 | 数据类型 | 默认值 | 说明 | Excel列名 |
|--------|---------|-------|------|----------|
| `exposure_users` | INT | 0 | 曝光人数 | 曝光人数 |
| `click_users` | INT | 0 | 点击人数 | 点击人数 |
| `add_to_cart_users` | INT | 0 | 加购人数 | 加购人数 |
| `add_to_cart_rate` | DECIMAL(5, 2) | NULL | 加购率（%） | 加购率 |
| `like_count` | INT | 0 | 点赞数 | 点赞数 |

**营销漏斗**：
```
曝光人数 → 点击人数 → 加购人数 → 下单人数
```

**说明**：完整记录用户从看到商品到下单的全流程数据，用于分析转化率和商品吸引力。

---

#### 7️⃣ **元数据** (2 个字段)

| 字段名 | 数据类型 | 默认值 | 说明 |
|--------|---------|-------|------|
| `import_batch_id` | VARCHAR(50) | NULL | 导入批次ID（格式：ELEME_YYYYMMDDHHMMSS_xxxxxxxx） |
| `created_at` | DATETIME | CURRENT_TIMESTAMP | 数据创建时间 |

**索引**：`import_batch_id` - 索引（用于批量删除）

### 3. 用户行为分析
- 商品曝光-点击-加购-下单转化率
- 复购率分析
- 新客获取分析

### 4. 商品优化建议
- 售罄商品补货提醒
- 低转化率商品优化
- 高点赞商品推广

## 🔧 使用示例

### 导入数据
```python
from app.models import ElemeProductData

# 创建商品数据记录
product = ElemeProductData(
    data_date='2025-10-17',
    city='上海',
    store_name='圣比萨披萨（徐汇店）',
    store_id='5000610763',
    product_name='玛格丽特披萨',
    is_new_product='否',
    is_signature='是',
    sales_amount=1250.50,
    sales_volume=25,
    order_user_count=18,
    exposure_users=450,
    click_users=120,
    add_to_cart_users=30,
    repurchase_30d_rate=15.5
)
db.session.add(product)
db.session.commit()
```

### 查询数据
```python
# 查询某门店的所有商品
products = ElemeProductData.query.filter_by(
    store_id='5000610763',
    data_date='2025-10-17'
).all()

# 查询销售TOP10商品
top_products = ElemeProductData.query\
    .filter_by(data_date='2025-10-17')\
    .order_by(ElemeProductData.sales_amount.desc())\
    .limit(10)\
    .all()
```
