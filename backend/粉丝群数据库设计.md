# 饿了么粉丝群数据库设计

## 📋 字段清单（37个字段）

### 基础信息（4个字段）
1. 日期 - `data_date` (Date)
2. 门店名称 - `store_name` (String 200)
3. 门店编号 - `store_id` (String 50)
4. 门店所在城市 - `city` (String 50)

### 群基础信息（3个字段）
5. 是否达到建群门槛 - `reach_threshold` (String 50)
6. 创建粉丝群类型 - `group_type` (String 50)
7. 粉丝群数量 - `group_count` (Integer)

### 粉丝统计（12个字段）
8. 群粉丝人数 - `total_fans` (Integer)
9. 活跃粉丝人数 - `active_fans` (Integer)
10. 粉丝活跃率 - `fan_active_rate` (Decimal 10,2) %
11. 群访问粉丝人数 - `visit_fans` (Integer)
12. 粉丝群访问率 - `fan_visit_rate` (Decimal 10,2) %
13. 新入群粉丝人数 - `new_fans` (Integer)
14. 新入群粉丝占比 - `new_fan_ratio` (Decimal 10,2) %
15. 老粉丝群访问人数 - `old_visit_fans` (Integer)
16. 老粉丝群访问率 - `old_fan_visit_rate` (Decimal 10,2) %
17. 退群粉丝数 - `quit_fans` (Integer)
18. 退群粉丝占比 - `quit_fan_ratio` (Decimal 10,2) %

### 订单统计（3个字段）
19. 粉丝群订单量 - `group_order_count` (Integer)
20. 门店有效订单量 - `store_order_count` (Integer)
21. 粉丝群订单占比 - `group_order_ratio` (Decimal 10,2) %

### 入群礼（2个字段）
22. 入群礼订单量 - `welcome_gift_orders` (Integer)
23. 入群礼领取量 - `welcome_gift_received` (Integer)

### 群普通红包（4个字段）
24. 群普通红包订单量 - `normal_redpack_orders` (Integer)
25. 群普通红包领取人数 - `normal_redpack_receivers` (Integer)
26. 群普通红包使用人数 - `normal_redpack_users` (Integer)
27. 群普通红包领取量 - `normal_redpack_received` (Integer)

### 群口令红包（4个字段）
28. 群口令红包订单量 - `password_redpack_orders` (Integer)
29. 群口令红包领取人数 - `password_redpack_receivers` (Integer)
30. 群口令红包使用人数 - `password_redpack_users` (Integer)
31. 群口令红包领取量 - `password_redpack_received` (Integer)

### 群活跃度（2个字段）
32. 活跃粉丝群数量 - `active_group_count` (Integer)
33. 有商家发消息的粉丝群数量 - `merchant_message_group_count` (Integer)

### 群配置（4个字段）
34. 是否配置进群礼 - `has_welcome_gift` (String 50)
35. 发送群专属优惠券次数 - `send_coupon_times` (Integer)
36. 发送推荐商品次数 - `send_product_times` (Integer)
37. 是否配置群公告 - `has_announcement` (String 50)

## 📊 数据表结构

### 表名：`eleme_fans_data`

```sql
CREATE TABLE eleme_fans_data (
    -- 主键
    id INT PRIMARY KEY AUTO_INCREMENT,
    
    -- 基础信息
    data_date DATE NOT NULL,
    store_name VARCHAR(200) NOT NULL,
    store_id VARCHAR(50),
    city VARCHAR(50),
    
    -- 群基础信息
    reach_threshold VARCHAR(50),
    group_type VARCHAR(50),
    group_count INT DEFAULT 0,
    
    -- 粉丝统计
    total_fans INT DEFAULT 0,
    active_fans INT DEFAULT 0,
    fan_active_rate DECIMAL(10,2) DEFAULT 0,
    visit_fans INT DEFAULT 0,
    fan_visit_rate DECIMAL(10,2) DEFAULT 0,
    new_fans INT DEFAULT 0,
    new_fan_ratio DECIMAL(10,2) DEFAULT 0,
    old_visit_fans INT DEFAULT 0,
    old_fan_visit_rate DECIMAL(10,2) DEFAULT 0,
    quit_fans INT DEFAULT 0,
    quit_fan_ratio DECIMAL(10,2) DEFAULT 0,
    
    -- 订单统计
    group_order_count INT DEFAULT 0,
    store_order_count INT DEFAULT 0,
    group_order_ratio DECIMAL(10,2) DEFAULT 0,
    
    -- 入群礼
    welcome_gift_orders INT DEFAULT 0,
    welcome_gift_received INT DEFAULT 0,
    
    -- 群普通红包
    normal_redpack_orders INT DEFAULT 0,
    normal_redpack_receivers INT DEFAULT 0,
    normal_redpack_users INT DEFAULT 0,
    normal_redpack_received INT DEFAULT 0,
    
    -- 群口令红包
    password_redpack_orders INT DEFAULT 0,
    password_redpack_receivers INT DEFAULT 0,
    password_redpack_users INT DEFAULT 0,
    password_redpack_received INT DEFAULT 0,
    
    -- 群活跃度
    active_group_count INT DEFAULT 0,
    merchant_message_group_count INT DEFAULT 0,
    
    -- 群配置
    has_welcome_gift VARCHAR(50),
    send_coupon_times INT DEFAULT 0,
    send_product_times INT DEFAULT 0,
    has_announcement VARCHAR(50),
    
    -- 元数据
    import_batch_id VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    -- 索引
    INDEX idx_data_date (data_date),
    INDEX idx_store_name (store_name),
    INDEX idx_store_id (store_id),
    INDEX idx_city (city),
    INDEX idx_batch (import_batch_id)
);
```

## 📝 字段分类汇总

- **基础信息**: 4个字段
- **群基础信息**: 3个字段
- **粉丝统计**: 11个字段（包含9个百分比率）
- **订单统计**: 3个字段（包含1个百分比）
- **入群礼**: 2个字段
- **群普通红包**: 4个字段
- **群口令红包**: 4个字段
- **群活跃度**: 2个字段
- **群配置**: 4个字段

**总计**: 37个业务字段 + 2个元数据字段 = 39个字段

## 🎯 必填字段

- `data_date`: 日期（必填）
- `store_name`: 门店名称（必填）

---

## 📌 注意事项

1. **日期格式**: 支持整数格式（如 20251019），已在 `_parse_date` 中处理 ✅
2. **百分比字段**: 自动识别为 `Decimal` 类型（以 `_rate` 或 `_ratio` 结尾）
3. **计数字段**: 自动识别为 `Integer` 类型（以 `_count`、`_fans`、`_orders`、`_times` 等结尾）
4. **配置字段**: 字符串类型（如"是"/"否"）
