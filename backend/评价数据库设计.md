# 饿了么评价数据库设计文档

## 📋 概述

本文档详细说明了饿了么评价数据表 `eleme_review_data` 的设计。该表用于存储从饿了么平台导出的顾客评价和商家回复数据。

---

## 🗂️ 数据表结构

### 表名：`eleme_review_data`

### 字段清单（共 19 个核心字段）

#### 1️⃣ **基础信息** (4 个字段)

| 字段名 | 数据类型 | 是否必填 | 说明 | Excel列名 |
|--------|---------|---------|------|----------|
| `id` | INT | 是 | 自增主键 | - |
| `data_date` | DATE | 是 | 数据日期 | 日期 |
| `store_id` | VARCHAR(50) | 否 | 门店ID | 门店ID |
| `store_name` | VARCHAR(200) | 是 | 门店名称 | 门店名称 |
| `city` | VARCHAR(50) | 否 | 城市名称 | 城市名称 |

**索引**：
- `data_date` - 索引（按日期查询）
- `store_id` - 索引（按门店ID查询）
- `store_name` - 索引（按门店查询）
- `city` - 索引（按城市筛选）

---

#### 2️⃣ **订单与评价信息** (2 个字段)

| 字段名 | 数据类型 | 默认值 | 说明 | Excel列名 |
|--------|---------|-------|------|----------|
| `order_id` | VARCHAR(100) | NULL | 订单ID（允许重复） | 订单ID |
| `review_time` | DATETIME | NULL | 评价时间 | 评价时间 |

**索引**：
- `order_id` - 索引（按订单查询）
- `review_time` - 索引（按评价时间排序）

**说明**：
- 订单ID允许重复（同一订单可能多次导出）
- 评价时间用于统计评价趋势

---

#### 3️⃣ **评分数据** (4 个字段)

| 字段名 | 数据类型 | 默认值 | 说明 | Excel列名 | 取值范围 |
|--------|---------|-------|------|----------|---------|
| `overall_score` | DECIMAL(3, 1) | NULL | 总体评分 | 总体评分 | 1.0 - 5.0 |
| `taste_score` | DECIMAL(3, 1) | NULL | 味道评分 | 味道评分 | 1.0 - 5.0 |
| `packaging_score` | DECIMAL(3, 1) | NULL | 包装评分 | 包装评分 | 1.0 - 5.0 |
| `delivery_score` | DECIMAL(3, 1) | NULL | 配送评分 | 配送评分 | 1.0 - 5.0 |

**说明**：
- 所有评分采用5分制
- 支持小数（如 4.5 分）
- 可用于计算平均评分、好评率等

---

#### 4️⃣ **评价内容** (2 个字段)

| 字段名 | 数据类型 | 说明 | Excel列名 |
|--------|---------|------|----------|
| `review_content` | TEXT | 顾客评价内容（长文本） | 评价内容 |
| `reply_content` | TEXT | 商家回复内容（长文本） | 回复内容 |

**说明**：
- 支持长文本存储
- 可用于文本分析和情感分析
- 回复内容可能为空（未回复）

---

#### 5️⃣ **商品反馈** (2 个字段)

| 字段名 | 数据类型 | 说明 | Excel列名 |
|--------|---------|------|----------|
| `liked_products` | TEXT | 点赞商品列表 | 点赞商品 |
| `disliked_products` | TEXT | 点踩商品列表 | 点踩商品 |

**说明**：
- 存储顾客点赞/点踩的商品信息
- 可能包含多个商品（用分隔符分开）
- 用于商品质量分析

---

#### 6️⃣ **状态字段** (4 个字段)

| 字段名 | 数据类型 | 说明 | Excel列名 | 可能值 |
|--------|---------|------|----------|--------|
| `is_appeal_success` | VARCHAR(10) | 是否申诉成功 | 是否申诉成功 | 是/否 |
| `is_counted_in_score` | VARCHAR(10) | 是否计入总分 | 是否计入总分 | 是/否 |
| `is_visible_to_customer` | VARCHAR(10) | 顾客是否会看到 | 顾客是否会看到 | 是/否 |

**说明**：
- 用于管理评价的可见性和有效性
- 申诉成功的评价可能不计入总分

---

#### 7️⃣ **订单详情** (1 个字段)

**说明**：
- 存储完整的订单信息

---

#### 8️⃣ **元数据** (2 个字段)

| 字段名 | 数据类型 | 默认值 | 说明 |

**索引**：`import_batch_id` - 索引（用于批量删除）

## 📊 数据分析维度

### 1. 评分分析
- 按门店/城市统计平均评分
- 各维度评分趋势（味道、包装、配送）
- 评分分布图（1-5分占比）

### 2. 好评率分析
```sql
-- 计算好评率（4分及以上）
SELECT 
    store_name,
    COUNT(*) as total_reviews,
    SUM(CASE WHEN overall_score >= 4.0 THEN 1 ELSE 0 END) as good_reviews,
    ROUND(SUM(CASE WHEN overall_score >= 4.0 THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) as good_rate
FROM eleme_review_data
GROUP BY store_name
```

### 3. 回复率分析
- 计算商家回复率
- 人工回复 vs 自动回复占比
- 回复及时性分析

### 4. 差评分析
- 识别低分评价（<3分）
- 分析差评原因（文本挖掘）
- 未回复差评监控

### 5. 商品反馈分析
- 最受欢迎商品（点赞最多）
- 需要改进商品（点踩最多）
- 商品评价关联分析

## 🔍 去重策略

### **当前策略：允许重复数据**

- ❌ 不进行去重检测
- ✅ 保留所有评价记录
- 📝 原因：同一评价可能在不同时间点导出，记录可能略有差异

### **建议的唯一性标识**

如果未来需要去重，建议组合：
- `data_date` + `order_id` + `review_time`

## 🛠️ 使用示例

### 导入数据
```python
from app.models import ElemeReviewData

# 创建评价数据记录
review = ElemeReviewData(
    data_date='2025-10-19',
    store_id='13131307',
    store_name='圣比萨披萨(玉环洪城店)',
    city='台州',
    order_id='500450601',
    review_time='2025-10-19 12:30:00',
    overall_score=5.0,
    taste_score=5.0,
    packaging_score=5.0,
    delivery_score=5.0,
    review_content='周国良师傅很好大姐',
    reply_content='感谢您的支持！',
    is_counted_in_score='是',
    is_visible_to_customer='是',
    reply_method='人工'
)
db.session.add(review)
db.session.commit()
```

### 查询数据
```python
# 查询某门店的所有评价
reviews = ElemeReviewData.query.filter_by(
    store_id='13131307',
    data_date='2025-10-19'
).all()

# 查询低分评价
bad_reviews = ElemeReviewData.query\
    .filter(ElemeReviewData.overall_score < 3.0)\
    .filter(ElemeReviewData.data_date == '2025-10-19')\
    .all()

# 统计平均评分
from sqlalchemy import func
avg_score = db.session.query(
    func.avg(ElemeReviewData.overall_score)
).filter_by(store_name='圣比萨披萨(玉环洪城店)').scalar()
```

## ⚠️ 注意事项

### **1. 数据隐私**
- 评价内容可能包含敏感信息
- 建议做好数据访问权限控制
- 导出时注意脱敏处理

### **2. 文本分析**
- 评价内容适合做情感分析
- 可以提取关键词和热点问题
- 建议使用NLP技术进行文本挖掘

### **3. 回复管理**
- 区分人工回复和自动回复
- 跟踪回复及时性
- 未回复评价需要提醒

### **4. 数据完整性**
- 部分字段可能为空（如未回复）
- 评分字段可能为空（未评分）
- 需要做好空值处理
