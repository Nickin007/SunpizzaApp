📊 数据表结构总览
--------------------------------------------------------------------------------

表名：eleme_product_data

[1] 基础信息（5个字段）
    ├─ data_date          日期 ⭐必填
    ├─ city               城市名称
    ├─ store_name         门店名称 ⭐必填
    ├─ store_id           门店编号
    └─ product_name       商品名称 ⭐必填

[2] 商品属性（5个字段）
    ├─ is_new_product     是否新品
    ├─ is_signature       是否招牌
    ├─ is_combo           是否套餐
    ├─ is_ingredient      是否配料
    └─ is_sold_out        是否售罄

[3] 销售数据（5个字段）
    ├─ sales_amount            销售额（元）
    ├─ sales_volume            销量
    ├─ order_user_count        下单人数
    ├─ order_count             带来订单数
    └─ order_transaction_amount 订单交易额（元）

[4] 复购数据（2个字段）
    ├─ repurchase_30d_users    近30日复购人数
    └─ repurchase_30d_rate     近30日复购率（%）

[5] 新客数据（2个字段）
    ├─ new_customer_count      新客人数
    └─ new_customer_ratio      新客占比（%）

[6] 用户行为（5个字段）
    ├─ exposure_users          曝光人数
    ├─ click_users             点击人数
    ├─ add_to_cart_users       加购人数
    ├─ add_to_cart_rate        加购率（%）
    └─ like_count              点赞数

总计：24 个核心字段 ✅

🗂️ 索引设计
--------------------------------------------------------------------------------

索引字段（共6个）：
  1. data_date          - 按日期查询
  2. city               - 按城市筛选
  3. store_name         - 按门店查询
  4. store_id           - 按门店ID查询
  5. product_name       - 按商品名查询

🚀 部署步骤
--------------------------------------------------------------------------------

方式一：使用部署脚本（推荐）
  
  cd backend
  .\deploy_product_database.ps1
  
  脚本会自动完成：
  ✅ 上传 models.py
  ✅ 上传 excel_parser.py
  ✅ 上传迁移脚本
  ✅ 执行数据库迁移
  ✅ 重启后端服务

方式二：手动部署

  1. 上传文件
     scp app/models.py ubuntu@118.89.73.199:~/SunpizzaApp/backend/app/
     scp app/services/excel_parser.py ubuntu@118.89.73.199:~/SunpizzaApp/backend/app/services/
     scp deploy/migrate_add_product_table.py ubuntu@118.89.73.199:~/SunpizzaApp/backend/deploy/
  
  2. 执行迁移
     ssh ubuntu@118.89.73.199
     cd ~/SunpizzaApp/backend
     source venv/bin/activate
     python deploy/migrate_add_product_table.py
  
  3. 重启服务
     sudo systemctl restart sunpizza-backend

📝 注意事项
--------------------------------------------------------------------------------

1. 数据去重策略
   - 建议使用：(product_name + data_date + store_id) 作为唯一性约束
   - 或在业务逻辑层实现去重

2. 数据类型说明
   - 是否类字段：使用 VARCHAR(10) 存储"是"/"否"
   - 金额字段：使用 DECIMAL(12,2) 保证精度
   - 百分比字段：使用 DECIMAL(5,2) 存储（如：15.50 表示 15.50%）

3. 性能优化
   - 已为常用查询字段添加索引
   - 建议定期清理历史数据
   - 可考虑按月份分表

4. 数据完整性
   - 必填字段：日期、门店名称、商品名称
   - 其他字段允许为空
   - 数字类型字段默认值为 0
